## Google Account Configuration (Gmail SMTP)

To enable sending emails via the Gmail SMTP server at no cost and without them going to spam:

1. Log in to your Google account (`robe.ingenito@gmail.com`).
2. Go to **Security** in the account settings.
3. Enable **Two-Step Verification** (if you haven't already).
4. Search for **App Passwords** in the Google account settings search bar.
5. Create a new app password, name it (e.g. `Cashly`) and copy the generated **16-character** code (without spaces).

---

## Environment and Docker Configuration

Add the following environment variables to your `.env` file, filling in the app password generated by Google:

```ini
# Direct SMTP configuration with Gmail (Solves spam for @gmail.com)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=robe.ingenito@gmail.com
SMTP_PASSWORD=your_16_characters_without_spaces
SMTP_FROM_EMAIL=robe.ingenito@gmail.com
SMTP_FROM_NAME=Cashly
```
